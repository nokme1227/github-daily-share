它到底是幹嘛的

再把規則講一次，免得空榜看起來像出錯。主榜候選要同時過三關：今日新增 ≥200 星、增幅 ≥5%、昨日基數 ≥500 星；增幅 = 今日新增 ÷ 昨日總星，昨日總星是總星減掉今日新增。過了三關的才按增幅排序，取前三名；過了三關還要再過實用複核（有趣、有能學到的點就算過），通不過的順延，不硬湊。今天日榜頁面解析出 11 條非贊助專案，其中今日新增 ≥200 的有 8 個，三關裡基數和新增都沒人掉隊——全場 8 個候選，基數最小的 openvino 也有 11,308 星，新增最少的也有 +246 星——偏偏增幅這一關全軍覆沒。三名最接近的各有各的來頭：Ghost-Downloader-3 號稱「下載器的集大成者」，一天 +449 星是全場絕對新增第四多，基數 12,228 星也不小，增幅就是上不去；stitch-skills 是 Google Labs 給 Stitch MCP 伺服器寫的 agent 技能庫，按 Agent Skills 開放標準寫，給 Antigravity、Gemini CLI、Claude Code、Cursor 這些 coding agent 用，一天 +303 星、增幅 2.91%；cursor/plugins 是 Cursor 官方的插件規範加官方插件，一天 +383 星、增幅 2.23%。實用複核今天一樣沒有候選可審——門檻前面就沒人排隊。

今天卡在哪

卡在「增幅這一關全場失守」。11 月 8 日那次還能說是門檻太嚴——當時門檻還是增幅 10%、基數 1000——今天門檻已經是放寬後的 5% 了，全場天花板 3.67% 還是夠不著，說明今天不是門檻的問題，是市況的問題。對照絕對榜就更清楚了：last30days-skill +952、CLI-Anything +899、firecrawl +795，絕對新增前三名的數字一點都不難看，但它們的總星分別是 70,776、60,533、204,173，基數太大，增幅只剩 1.36%、1.51%、0.39%。大專案穩穩地漲、小專案集體熄火的一天，增幅榜自然就空了。這也剛好驗證了增幅榜的設計初衷：它量的是「起勢」，不是「規模」，規模大的人今天再穩，也上不了這張榜。

值得學什麼

最值得偷的是 「空榜本身也是一種信號」：放寬門檻後連著十天都有人入選，今天第一次掛零，而且是全場 8 個候選集體卡在同一關上——這種「集體失守」和 11 月 8 日「三個人三種死法」是兩種不同的空法。前者說的是「今天沒人起勢」，後者說的是「門檻剛好卡住人」。寫複核報告、寫選股筆記時也可以偷這個分法：先看空缺是「個體原因」還是「整體原因」，再決定要不要動規則。另一招是 「看增幅要先看分母那一欄」：firecrawl 一天 +795 星，絕對數字全場第三，增幅卻只有 0.39%——分母 20 萬星擺在那裡，再大的單日新增也翻不起浪。只看新增數字不看基數，會把「穩」誤讀成「猛」，跟看財報只看成長額、不看基期是一樣的毛病。

我們怎麼用：今天一樣沒有新主榜可試，但有三個名字值得先放進觀察名單，不用現在裝。Ghost-Downloader-3 明天如果再漲一波、增幅過線，它就是主榜候選——家裡機器多、常要抓檔案的人，下載器這種工具遲早用得上，到時候再看它到底集了哪些下載器的大成。stitch-skills 更值得盯：我們自己的技能文件越來越多（六大指標計分、P1 自查、實用複核），Google Labs 這套按開放標準寫技能庫的做法，正好可以對照著學——技能怎麼拆、怎麼讓不同 agent 都載得起來。cursor/plugins 則是 Cursor 插件規範的官方出處，寫插件之前先讀規範，別自己發明格式。至於絕對榜前三的 last30days-skill（跨 Reddit、X、YouTube、HN 做主題研究的 agent 技能）和 CLI-Anything（讓所有軟體都變 agent 原生），都已經是幾萬星的大專案了，不急著今天裝，先記著。
