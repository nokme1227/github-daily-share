Modern Web Guidance：第三天了，還在漲，而且漲得挺體面

GoogleChrome / modern-web-guidance-src · Apache-2.0 協議 · TypeScript · 250 個現代網頁特性指南 · Chrome、Edge、Firefox、MDN 四方聯手維護

插畫：連莊第三天，柱子回落了，但還站在第一天的 1.5 倍上面——這才是熱度站住的樣子。

一句話人話

第三天了，還在漲：一天 +1,225 星、增幅 25.62%，總星 6,007。三天合計 +3,899 星，總星從 2,866 漲到 6,007，兩天翻了一倍多。

它到底是幹嘛的

基礎介紹見 11-12、11-13 兩期：給 AI 程式工具裝的技能，npx modern-web-guidance@latest install 一行裝好，內含 250 個現代網頁特性指南，查指南用 search、取全文用 retrieve、掃老寫法用 legacy-scan .。今天只補新看點：第一，增幅回落了，但回落得健康——從 63.99% 回到 25.62%，這才是正常的第三天：第一天是嚐鮮、第二天是口碑爆發、第三天還能守住兩成五，說明留下來的人是真的在用，不是看熱鬧。第二，動手的人還在增加：fork 數從昨天的 268 個漲到 401 個，漲星的人裡，真拿去裝的比例沒掉。第三，維護沒停：11-14 當天仍有更新進主線。

它火在哪

一是「三天連莊」本身就很罕見：日榜是個喜新厭舊的地方，同一張臉連著三天站榜首，說明它不是一陣風。二是它踩在兩個熱點的交叉點上：「AI 寫程式」加上「瀏覽器四方聯手背書」，兩個題材各自都能漲，疊在一起就更不用說。三是數字結構健康：總星漲、fork 也漲，看熱鬧和動手的人一起來。

值得學什麼

前兩天講了「把最佳實踐寫成技能餵給 AI」和「熱度來的時候順手把工具變快」，今天補第三條：熱度第三天還在，靠的是「東西真的有用」，不是「第一天的新鮮感」。對照我們自己的工具站：新功能上線後第三天還有人用、還有人回來，才是真的站住了——第一天的掌聲不算數，第三天的回頭客才算。

我們怎麼用：用法跟前兩天一樣：還沒跑過 npx modern-web-guidance@latest legacy-scan . 的，今天掃一遍工具站程式碼——現在掃全站也不心疼了。它教的是「寫法」，不是「長相」——頁面長什麼樣，還是 Hallmark 那套說了算。

Veyra：GTA6 倒數四天，版本先升到了 2.1.6

Likely7 / Veyra-NRVideo · GPL-3.0 協議 · C++ · Windows 11 · DirectX 12 · 目前版本 2.1.6 · 支援 NVIDIA 與 AMD 顯卡

插畫：GTA6 還有四天上市，Veyra 先把版本升到了 2.1.6——強化的，是擷取進電腦的那路畫面，不是 PS5 本體跑出來的幀數。

一句話人話

昨天第二名，今天還是第二名：一天 +423 星、增幅 23.51%，總星 1,614 → 2,222——增幅比昨天（17.9%）還高了一截。版本也升到了 2.1.6，GTA6 倒數四天。

它到底是幹嘛的

基礎介紹見上一期：Windows 即時 GPU 影片強化，把本地影片、擷取卡、遊戲串流接進一條即時強化管線：超解析、降噪、HDR、補幀、擷取，PS5、Xbox、PC 串流都能接。今天只補新看點：2.1.6 版的東西很實在——即時重播（按 F9）、麥克風混音與分軌、全部特效排除、VFR 去重（60 幀去到 30 幀），都是打遊戲、錄影、直播時真的會用到的功能，不是湊數的更新。README 還寫著一串下載數：可攜包累計下載 79,332 次（截至 2026-11-08），全部 Release 檔案加起來 103,337 次——下載量跟漲星對得上，不是只有星、沒人裝。

它火在哪

一是節點踩得準：GTA6 11 月 19 日上市，倒數四天，所有跟「到時候畫面怎麼看」有關的東西都在漲。二是它昨天說的「讓 PS5 的 GTA6 跑上 120FPS」那句話雖然要打折（上一期已說明：強化的是擷取畫面，不是主機渲染幀數），但大家買單的其實是另一件事——一台 Windows 電腦就能把遊戲畫面即時「加料」，這個需求是真的。三是出貨節奏對：漲星的當口，版本跟著升，來看熱鬧的人一進門就看到新東西。

值得學什麼

README 有個很值得偷的習慣：效能數字敢寫具體數字。它寫 RTX 5070 上 FXAA 約 0.15 毫秒、4K 單面網格美顏約 1.42 毫秒，還老實註明「成本隨內容與硬體而異」。比起「超快」「極致流暢」這種形容詞，具體數字加一句限制條件，反而更讓人信。我們寫工具站報告也一樣：數字具體，才有人信；吹牛不打折，才有人回頭。

我們怎麼用：家裡有 PS5 加擷取卡的話，GTA6 上市那天可以試試把畫面接進電腦跑 Veyra；沒有擷取卡也沒關係，本地影片強化也能玩。安裝就是去 Releases 頁下載最新版可攜包，不用編譯。上一期的提醒再說一次：「120FPS」那句話要打折，別當成主機效能的承諾。

Claude Trading Skills：不給明牌，只教你怎麼做投資功課

tradermonty / claude-trading-skills · MIT 協議 · Python · Claude Skills 架構的交易流程工具包 · 僅供研究、不是投資建議

插畫：這專案的核心就是這個圈——盤檢、風控、計畫、日誌、檢討，轉一圈回來，再盤檢一次。

一句話人話

給 Claude Code 的投資流程技能包，一天 +556 星、增幅 13.15%，總星 4,783。先說清楚：它不給明牌、不下單、不承諾賺錢——README 一開頭就把這三句話寫明白了，教的是「怎麼做投資功課的流程」。

它到底是幹嘛的

這是作者為自己做的工具，後來開源出來的：一套 Claude Skills 架構的交易流程工具包，給時間不夠的個人投資者。定位是長期投資、ETF、股息股為主，紀律波段為輔；目標不是把買賣決定外包給 AI，而是把市場檢視、風險管理、交易計畫、交易日誌、持續改進結構化。README 明確寫：不是訊號服務、不承諾獲利，僅供教育、研究與流程改進。入門有五條路：market-regime-daily（15 分鐘每日盤檢）、core-portfolio-weekly（每週長期組合檢視）、swing-opportunity-daily（只在風險允許時找波段機會）、trade-memory-loop（每筆平倉交易都留記錄、做檢討）、monthly-performance-review（每月績效檢討、調整規則）。技能包括市場寬度分析、趨勢分析、曝險教練、VCP 篩選、回撤斷路器、技術分析、倉位計算、交易記憶核心、訊號事後檢討等。沒付費數據 API 也能起步：五個技能（市場寬度分析、趨勢分析、倉位計算、交易記憶核心、訊號事後檢討）用公開 CSV、圖表截圖、本地檔案就能跑。安裝是 clone 下來，或從 skill-packages/ 拿預打包的 .skill 上傳到 Claude 網頁版 Skills 頁。

它火在哪

一是踩在兩個熱點的交叉點上：「Claude Skills 生態」加上「投資流程」，兩個題材各自都能漲。二是它反其道而行：別的投資工具都在比「訊號多準」，它一開頭就說「我不給訊號」——在滿是明牌的圈子裡，「不給明牌」本身就是一種信任狀。三是它的使用門檻想得很周到：免付費 API 的起步路徑寫在 README 最顯眼的位置，沒訂閱也能先跑起來，願意試的人就多了。

值得學什麼

「流程比判斷值錢」——跟 TradingAgents 是同一課，只是這次的主角是個人投資者。特別是兩招可以直接偷：trade-memory-loop（每筆平倉交易都留記錄、做檢討，虧的賺的都算數）和 drawdown-circuit-breaker（虧損到線就斷電，不讓一筆交易拖垮整個組合）。這兩招換到我們的個股報告復核流程裡就是：每期結算留檔、觸線就停手——紀律不是寫在牆上的，是寫進流程裡、到點自動觸發的。

我們怎麼用：先潑一盆冷水：別拿它來選股下單，更別拿計劃資金實盤——先模擬盤走一段時間，流程跑順了再說。值得偷的是它的工作流設計：market-regime-daily 的 15 分鐘盤檢清單，可以對照我們的六檔復核流程改一版「每日盤檢」清單；trade-memory-loop 的交易日誌迴圈，可以對照我們的結算留檔想一想。僅供研究、不是投資建議——這句話，作者寫在 README 裡，咱們也原樣貼在這裡。
