它到底是幹嘛的

再把規則講一次，免得空榜看起來像出錯。主榜候選要同時過三關：今日新增 ≥200 星、增幅 ≥5%、昨日基數 ≥500 星；增幅 = 今日新增 ÷ 昨日總星，昨日總星是總星減掉今日新增。過了三關的才按增幅排序，取前三名；過了三關還要再過實用複核（有趣、有能學到的點就算過），通不過的順延，不硬湊。今天日榜頁面解析出 11 條非贊助專案，其中今日新增 ≥200 的有 9 個，基數最小的也有上萬星——三關裡基數和新增都沒人掉隊，偏偏增幅這一關全軍覆沒。三名最接近的各有各的來頭：Ghost-Downloader-3 是 GPL-3.0 協議的下載器，號稱「下載器的集大成者」，一個 App 收下 HTTP、磁力／BT、FTP、M3U8、DASH、eD2k，YouTube 和 B 站還能選片段、選畫質、抓字幕，四個平台都有，提交已逾 1,800 次；AutoClip 是 MIT 協議的開源 AI 影片剪輯工具，長影片貼個連結就能自動剪成短片，連字幕、封面和發文文案一起給，提交已逾 1,500 次；stitch-skills 是 Apache-2.0 協議的 Google Stitch 設計技能庫，按 Agent Skills 開放標準寫，分設計、建置、工具三組外掛，給 Codex、Antigravity、Gemini CLI、Claude Code、Cursor 這些 coding agent 用。實用複核今天一樣沒有候選可審——門檻前面就沒人排隊。

今天卡在哪

卡在「分母長得比分子快」。Ghost 昨天總星 18,218、今天 19,088，一天多了 887 星，絕對數字是全場第二多；AutoClip 昨天 16,133、今天 16,917，一天多了 770 星，也是全場第三多。問題是分母——昨日總星分別是 18,201 和 16,147——再大的單日新增，除以一萬六、一萬八的分母，也翻不起 5% 的浪。昨天它們能過線，是因為昨天的分母還小一點、新增還多一點；今天新增少了一截，分母又大了一圈，兩頭一擠，就差了那 0.13 和 0.23 個百分點。這也剛好驗證了增幅榜的設計初衷：它量的是「起勢」，不是「規模」——規模長大了，起勢的門檻就跟著變高，連莊本來就一天比一天難。

值得學什麼

最值得偷的是 「看增幅要先看分母那一欄」：Ghost 一天 +887 星，絕對數字全場第二，增幅卻只有 4.87%——分母 18,201 星擺在那裡，再大的單日新增也翻不起浪。只看新增數字不看基數，會把「穩」誤讀成「猛」，跟看財報只看成長額、不看基期是一樣的毛病。另一招是 「連莊斷在哪裡，比連莊本身更說明問題」：AutoClip 連莊六天、Ghost 回榜三天，斷點不是「沒人理了」，而是「分母追上來了」——這種斷法，說明產品還在被新的人發現，只是發現的速度追不上星數的底盤。寫複核報告、寫選股筆記時也可以偷這個分法：先問「是需求沒了，還是基數大了」，再決定要不要動規則。

先說清楚邊界：Ghost-Downloader-3 是個下載工具，能下載什麼、該不該下載，要看內容本身的授權與平台規則——只抓自己有權取得的內容，別拿它去繞過付費牆、抓盜版或侵犯著作權。它本身不是惡意程式、詐騙、色情或政治敏感內容，所以照常列入近門檻對照；但怎麼用，是使用者的責任。
我們怎麼用：今天一樣沒有新主榜可試，但有三個名字值得先放進觀察名單，不用現在裝。Ghost-Downloader-3 明天如果再漲一波、增幅過線，它就是主榜候選——常抓公開數據集、模型權重或工具站要用的公開大檔案的人，可以先看它 README 裡的命令列流程：ghd probe 先預覽、ghd add --select 只抓要的檔案、ghd wait 等完再往下走。AutoClip 也不用急著今天裝，內建示例不用 API Key 就能先試，流程合用再接自己的模型；命令列流程是 autoclip produce talk.mp4 --srt talk.srt --platform tiktok --portrait-style podcast --json，版本以 autoclip --version 為準，只剪自己有權使用的素材。stitch-skills 更值得盯：我們自己的技能文件越來越多（六大指標計分、P1 自查、實用複核），Google Labs 這套按開放標準寫技能庫的做法，正好可以對照著學——技能怎麼拆成設計、建置、工具三組、怎麼讓不同 agent 都載得起來，Claude Code／Cursor 的裝法 README 裡寫的是 npx plugins add google-labs-code/stitch-skills --scope project --target claude-code 這一類命令，先讀規範再動手。
