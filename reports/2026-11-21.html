Ghost-Downloader-3：連漲三天，靠的不是第一天的新鮮感

XiaoYouChR / Ghost-Downloader-3 · GPL-3.0 協議 · Python · Windows／macOS／Linux／Android 四平台 · fork 數 876 個

插畫：昨天講了「一個頂五個」，今天補另一半——網路再爛也能續傳，本體之外還有一套正在長大的外掛生態。

一句話人話

號稱「下載器的集大成者」：HTTP、磁力／BT、FTP、M3U8、DASH、eD2k 全包，YouTube 和 B 站還能選片段、選畫質、抓字幕。一天 +774 星、增幅 5.67%，總星 14,424——11 月 19 日它還差門檻 1.33 個百分點，11 月 20 日 +1,082 星，今天再 +774 星，三天合計 +2,305 星。

它到底是幹嘛的

昨天已經講過全貌，今天只補昨天沒展開的兩處，都是 README 裡白紙黑字寫著的。第一，README 的第一條功能寫的不是「支援多少協議」，而是「爛網路才是真正的考驗」：智慧分塊不用合併檔案、自動偵測頻寬、真實瀏覽器的 TLS 指紋、斷點續傳進度不丟——下載器好不好用，順暢的時候看不出來，網路差的時候才見分曉。第二，路線圖（Roadmap）只有兩條：把外掛 API 公開（Feature Packs 系統已經在跑、API 還在穩定中），以及更強的任務編輯（例如把多個 Session 綁到同一個任務）。換句話說，作者接下來要做的，是讓別人也能往這個下載器上掛東西。命令列工具 ghd 照舊在設定裡安裝：ghd probe <url> 先預覽、ghd add <url> --select 0,3 -o ./downloads 只抓指定的檔案、ghd wait tsk_0123 等它下完；GPL-3.0 開源，fork 數從昨天的 837 個漲到 876 個。

它火在哪

一是連漲本身就是訊號：一天爆紅可能是新聞，三天連漲（+449、+1,082、+774）是有人裝了、用了、回來推給別人——昨天我們說「不是一天的新聞」，今天這句話又被驗證了一次。二是它把最難的那一關先講清楚：README 不先吹協議多全，先講爛網路、斷點續傳、進度不丟——這些才是下載器每天真正被罵的地方。三是外掛生態的想像空間：本體已經「一個頂五個」，再把外掛 API 公開，別人寫的外掛包就能讓它繼續長，作者不用什麼都自己寫。

值得學什麼

最值得偷的是 「先講最難的場景，再講功能清單」：README 的功能第一條是爛網路下的表現，不是協議數量——寫我們自己的工具介紹時也一樣，先講最容易翻車的那個場景怎麼扛，再列功能，使用者才知道這東西經不經得起用。另一招是 「路線圖只寫兩條」：公開外掛 API、更強的任務編輯，兩條都跟「讓別人接進來、讓任務更好改」有關——路線圖短，才看得出主線；什麼都想做，常常等於什麼都沒說。

先說清楚邊界：這是個下載工具，能下載什麼、該不該下載，要看內容本身的授權與平台規則——只抓自己有權取得的內容，別拿它去繞過付費牆、抓盜版或侵犯著作權。它本身不是惡意程式、詐騙、色情或政治敏感內容，所以照常入選；但怎麼用，是使用者的責任。
我們怎麼用：常抓公開數據集、模型權重或工具站素材的人，可以先從 Releases 頁下載桌面版；寫腳本抓檔案的話，照 ghd probe、ghd add、ghd wait 這套介面寫進排程就行，斷點續傳那段尤其適合網路不穩的環境。對工具站來說，更值得記的是它的寫法：介紹一個工具，先講最難的場景、再列功能——我們寫期報的「它火在哪」，也可以照這個順序。

AutoClip：三個入口、一個版本號，桌面、CLI、MCP 一起更新

zhouxiaoka / autoclip · MIT 協議 · Python · 桌面版＋CLI＋MCP＋Docker · 剪輯渲染在本機完成 · fork 數 2,072 個

插畫：AutoClip 今天的新看點不在功能，在紀律——三個入口同步更新，版本號只有一個說法。

一句話人話

開源的 AI 影片剪輯桌面工具：貼一個長影片連結，選好要發的平台，它自動剪出短影片，連字幕、封面和發文文案一起給你。一天 +689 星、增幅 5.67%，總星 12,833——昨天 +983 星登頂，今天再漲一天，兩天合計 +1,672 星。

它到底是幹嘛的

核心流程昨天講過了，今天補 README 裡新看到的三處細節。第一，README 開頭就寫明：最新正式版，桌面、CLI 與 MCP 同步更新，版本以 autoclip --version 和 MCP 的 get_version 為準——三個入口共用同一條鏈路，連版本號的說法都只有一個，不怕各說各話。第二，快速開始把使用場景分得很清：在電腦上出片走桌面版、自建 Web 服務或 Linux 走 Docker、批量處理或接入 agent 走 CLI／MCP，Docker 只要四步：git clone https://github.com/zhouxiaoka/autoclip.git、cp env.example .env、mkdir -p data logs uploads、docker compose up -d --build。第三，費用表現在是三條素材對照（昨天只提了一條）：1 小時 43 分的英文訪談 7.5 分鐘出 10 條、文字模型費用估算人民幣 0.09 元；2 小時 52 分的中文訪談 29.5 分鐘、0.20 元；舊版 2 小時 6 分的片子 65 分鐘、0.64 元——README 自己註明「不是同一輸入的速度對照」，費用只算文字模型、不含轉寫與生圖，實際帳單以所選服務商為準。CLI 照舊：autoclip produce talk.mp4 --srt talk.srt --platform douyin --portrait-style podcast --json，已有字幕可用 --srt 跳過轉寫。

它火在哪

一是連漲第二天，昨天的新鮮感還沒退，今天又漲 689 星——跟 Ghost 一樣，連續性本身就是有人在真用的證據。二是它把「怎麼選入口」寫得比功能更清楚：桌面、Docker、CLI／MCP 各對一種人，讀者不用先讀完整份文件才知道自己該從哪裡開始。三是版本紀律：三個入口同步更新、版本以命令列輸出為準——這種小地方最容易亂，作者先把它寫死，反而讓人敢在流程裡接它。

值得學什麼

最值得偷的是 「版本只有一個說法」：桌面、CLI、MCP 同步更新，版本以 autoclip --version 為準——我們工具站的數據也有同樣的毛病：頁面、腳本、複核表各寫各的日期，萬一對不上，誰說了算？先定一個「唯一說法」，再談別的。另一招是 「費用對照要註明口徑」：三條素材、三個數字，還專門註明不是同一輸入的對照、費用不含哪些項——數字敢寫具體、口徑敢寫清楚，反而更讓人信；只寫「超便宜」，沒人信。

我們怎麼用：手邊有長影片素材想剪短片的人，先從桌面版的示例項目看效果，不用 API Key；想把它接進流程的話，Docker 四步就能起一個 Web 版，CLI 的 produce 命令則適合批量處理。對工具站來說，今天最值得帶走的是那句「版本以命令輸出為準」：以後報告裡的數據口徑、快照日期，也該有這麼一個唯一說法，頁面、腳本、複核表都指同一處，別讓三份文件各寫各的。
