Orkas：别再雇一个 AI 助手了，直接雇一队，还都坐在你自己的电脑上

Orkas-AI / Orkas · MIT 协议 · 本地优先的多智能体桌面应用 · 最近提交 2026-10-31

插画：Orkas 的分工方式——你交代一个目标，指挥官拆成待办，分给对口的专科助手，干完拿回来给你验货。

一句话人话

一个开源、免费下载的桌面应用：你跟一个“指挥官”说目标，它把活拆成待办，分给 16 个内置专科助手，还能指挥你电脑上已有的 Claude Code、Codex、OpenCode、OpenClaw、Hermes-Agent 一起干，项目、记忆和文件都留在你本地。

它到底是干嘛的

先说它不是什么：它不是一个大模型，也不是一个聊天框。它是一个“团队架子”：项目装着目标、规则、记忆和文件，新会话不用从头交代；待办 + 自动推进让团队按清单自己往下干，干完拿回来给你看；定时自动化可以按小时、天、周、月重复跑例行活。16 个内置助手各有分工，README 里都写明了交付物：DeepResearcher 出带来源和矛盾标注的研究报告，SeoGeoAgent 给网址做技术审计，StockAnalyser 做股票研究、因子筛选、回测和组合风险检查，ContentWriter 写文章和通讯，PptMaker 出可编辑的 PPT，VideoStudio / VoiceStudio / ImageStudio 管视频、配音和图片，UIDesigner / ProductDeveloper 管界面和代码，OfficeWorker 管 Word / Excel / PPT / PDF，还有 5 个电商助手管选品、文案、评论和销售分析。另外它还能把外部的命令行助手当本地会话拉进来——编码的 Claude Code、Codex、OpenCode，个人助手 OpenClaw、Hermes-Agent——指挥官统一排一张计划，修 bug、审代码、写发布说明可以在一次对话里分给不同的人。装法 README 写了两条路：打包应用去官网下载 macOS / Windows 版（免费，附 500 点内置模型额度，不用 API 密钥也能起步），或者从源码跑，git clone https://github.com/Orkas-AI/Orkas.git，进目录跑 ./run.sh（macOS / Linux）或 run.cmd（Windows），需要 Node 22.12+，首次启动会在 ~/.orkas/ 建工作区，再去设置里加自己的模型密钥或本地兼容端点。README 也老实写了边界：共享项目、云同步、发布成网页应用这些只在打包版里有，开源版目前还没有；它跑在你的电脑上，电脑关了，自动推进和定时任务也就停了，v1.9 起唤醒后 12 小时内会补跑最近一次错过的任务。

它火在哪

一是“团队”这个比喻终于落到了可用的形态上：之前很多多智能体项目停在框架和代码层面，Orkas 直接给了桌面应用、待办清单和定时任务，普通人不用写编排代码就能使唤一队助手。二是它不搞“二选一”：你已经在用的 Claude Code、Codex 不用扔，指挥官把它们当队员编进来，等于在你现有的工具箱外面又套了一层项目管理和分工。三是更新没断档：仓库 2026-04-29 创建，今天凌晨（北京时间 2026-10-31）还有提交，昨天一天就涨了 1,118 星、增幅 22.34%，是本期唯一同时过三道门槛的候选。四是本地优先这句话有实料：对话、文件、知识库和自定义助手默认留在本机，自己带密钥时模型调用直接从本机走供应商，内置模型才走它的托管服务，密钥本地加密且不进云同步——对在意数据去向的人，这句比“我们很重视隐私”可信。

值得学什么

“持续的活”比“聪明的一答”更值得做成产品。Orkas 真正的产品化点不在模型多强，而在项目、待办、自动推进、定时任务这四件套：它们解决的是“昨天的活今天接着干、例行的活不用人人催”——这正是单次对话助手最弱的地方。第二个可抄的点是边界写在 README 明处：什么在开源版里、什么只在打包版里、关机了会停、错过的任务怎么补，一句话讲清，省得用户装完才发现货不对板。第三个点是不跟用户已有的工具抢位置：它不逼你换掉 Claude Code，而是把它们编进自己的分工里——做工具站也一样，新工具先想“怎么接进现有流程”，比“推倒重来”更容易落地。

我们怎么用：先别急着把它当主力，先拿它当“复核流程的排班表”试一版：给工具站建一个项目，把目标、数据口径、不能做成什么样写进项目规则，再把个股报告复核拆成待办——基本面一路、筹码一路、位阶一路各出结论，最后由指挥官汇总成一份待你验货的报告，结论和依据留档，改了口径先过测试再推。定时自动化可以先试最轻的一件：每周固定时间出一份“本周数据更新清单”，人看一眼再决定推不推，不要让它直接动仓库。提醒两句：第一，README 里那个 StockAnalyser 是股票研究工具，仅供研究、不是投资建议，更不要拿它直接下单或动用计划资金实盘——复核流程里它最多当“多一路观点”，拍板还是按咱们自己的规则来。第二，模型密钥只走你自己的供应商设置，别贴进仓库配置文件；打包版的 500 点免费额度用完要另外付费或换自己的密钥，这笔账先算清楚再上量。
